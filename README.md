# Mailroom

A learning project: I am learning programming fundamentals by building a
mailroom program in Python, following *The AI Agent Factory*, Chapter 13.
We learn with PRIMM: Predict, Run, Investigate, Modify, Make.

See [AGENTS.md](AGENTS.md) for the rules and what I have covered so far.

## Run it

Needs [uv](https://docs.astral.sh/uv/).

```
uv sync
uv run python main.py
uv run pyright
```
